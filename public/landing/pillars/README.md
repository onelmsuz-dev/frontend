# OneRoom benefit-card illustrations

Generated with the built-in `image_gen` tool as four compact, true-transparent 3D assets. The shared art direction uses cobalt glass, polished blue ceramic, frosted white acrylic, silver details, an isometric camera, and a contact shadow fading into alpha.

- `speed.png`: a speed gauge unified with phone, tablet, and laptop silhouettes.
- `security.png`: a blue shield protecting a database cylinder.
- `browser.png`: a browser frame and cloud representing use without installation.
- `support.png`: a headset and speech bubbles representing support in the user's language.

All files were verified as non-opaque RGBA PNG images.
