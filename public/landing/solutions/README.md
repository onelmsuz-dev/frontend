# OneRoom solution illustrations

Generated with the built-in `image_gen` tool for the ten cards in the landing page's Yechimlar section.

Shared prompt: premium minimal 3D icon-like editorial illustration for OneRoom; a centered single metaphor in translucent cobalt glass, polished royal-blue ceramic, frosted white acrylic, and subtle silver; pale seamless background, soft ground shadow, three-quarter isometric studio render; no text, logo, people, UI screenshot, cartoon treatment, confetti, clutter, or watermark.

The `*-transparent.png` files use true RGBA transparency created through background extraction. They contain only the object and its soft contact shadow, so the card's own background remains continuous behind every illustration. The distinct filenames also prevent stale optimized images from being served from the previous Next.js image cache.

Subjects:

- `crm.png`: a central hub linking four module tiles.
- `attendance.png`: attendance calendar with raised check tokens.
- `payments.png`: payment card entering a compact terminal.
- `debt.png`: balanced account blocks with a small amber reminder.
- `reports.png`: ascending data columns and an upward curve.
- `salary.png`: calculator, salary coins, and a graduation-cap form.
- `groups.png`: student tokens organized into group and room frames.
- `schedule.png`: weekly calendar with aligned lesson blocks.
- `telegram.png`: paper plane emerging from a notification bubble.
- `automation.png`: a looped workflow ribbon passing through process gates.
